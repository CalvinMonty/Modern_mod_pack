# Assets

This is the asset repository for Modern Mod Pack.

Files under `modern_mod_pack/` use the Minecraft asset namespace. Gradle copies this folder into the CurseForge jar as `assets/modern_mod_pack/`.

| Path | Contents |
| --- | --- |
| `modern_mod_pack/lang/` | Translation files |
| `modern_mod_pack/textures/` | Block and item textures |
| `modern_mod_pack/models/` | Block and item models |
| `modern_mod_pack/sounds/` | Sound events and audio |
