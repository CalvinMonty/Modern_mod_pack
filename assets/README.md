# Assets

Textures, models, language files, and sounds for Modern Mod Pack, under the `modern_mod_pack` namespace.

| Path | Contents |
| --- | --- |
| `modern_mod_pack/lang/` | Translation files |
| `modern_mod_pack/textures/block/` | Block textures |
| `modern_mod_pack/textures/item/` | Item textures |
| `modern_mod_pack/models/block/` | Block models |
| `modern_mod_pack/models/item/` | Item models |
| `modern_mod_pack/sounds/` | Sound events and audio |
