# Code

Java source and Gradle project for Modern Mod Pack, a Minecraft Forge 1.20.1 mod.

| Path | Contents |
| --- | --- |
| `src/main/java/` | Mod source (`ModernModPack.java` and later items, blocks, entities) |
| `src/main/resources/` | Forge metadata (`mods.toml`, `pack.mcmeta`) |
| `src/generated/resources/` | Files produced by data generation |
| `build.gradle` | Gradle build |
| `gradle.properties` | Mod id, version, and Minecraft/Forge versions |
