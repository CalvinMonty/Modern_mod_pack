# Code

Java source and Gradle project for Modern Mod Pack, a Minecraft Forge 1.20.1 mod.

| Path | Contents |
| --- | --- |
| `src/main/java/` | Java source (`ModernModPack.java`) |
| `src/main/resources/META-INF/` | Forge metadata (`mods.toml`) |
| `src/main/resources/pack.mcmeta` | Resource pack metadata |
| `src/generated/resources/` | Generated data |
| `build.gradle` | Gradle build |
| `gradle.properties` | Mod id, version, and Minecraft/Forge versions |
